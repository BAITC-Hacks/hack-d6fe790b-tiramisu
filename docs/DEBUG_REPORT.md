# Отчёт по отладке

## Исправлено

- Рекомендационная логика вынесена из HTTP-обработчика в отдельный сервис, поэтому её можно проверять без браузера.
- Загрузка JSONL валидирует структуру профиля, типы, даты и признак synthetic. Приоритет источников каталога определён явно.
- Занятость, бюджет, формат, язык и длительность возвращаются как проверяемые причины отсева. Выбранная дата и число занятых доступны даже при трёх показанных карточках.
- Количество кандидатов отделено от числа отображённых карточек. Интерфейс больше не сообщает, что других профилей нет, когда подходящих больше трёх.
- Порядок карточек фиксирован правилами ранжирования и tie-break по цене и ID.
- Сетевой вызов embeddings удалён из пути пользовательского запроса. Сервер использует один подготовленный snapshot либо deterministic lexical fallback.
- Интерфейс получил timeout запроса, единственный обработчик retry, явные статусы трёх исходов и summary фактически отправленного запроса.
- Объяснения карточек получают evidence только из полей профиля и условий запроса.
- Сценарии live-демо вынесены в единый manifest backend/data/demo-scenarios.json.
- Календари приведены к сезонной занятости: 37,5–40% осенью и 74,2% в декабре, с повышенной загрузкой выходных.
- Две цены кейтеринга приведены к пакетам за мероприятие; у смешанного фото-профиля задано ограничение присутствия 8 часов.
- При выборе демосценария очищаются необязательные поля прошлого запроса. Изменение формы после подбора не меняет параметры уже показанных карточек.
- Неверный JSON, специальные значения NaN/Infinity, ошибочные типы полей и выход за допустимые даты отклоняются с понятным ответом API.

## Что проверяется локально

    python -m unittest discover -s tests -v

Проверки охватывают контракт рекомендаций, валидацию каталога, повторяемость порядка, причины отсева, переключение дат и fallback при отсутствии embedding-artifact.

Дополнительные регрессии интерфейса (Node.js 18+, без пакетов):

    node --test tests/frontend.test.cjs

## Результат проверки 23.09.2026

- **16 Python-тестов прошли**: HTTP API, каталог, фильтры, обязательные и необязательные поля, манифест и ранжирование. Время финального прогона — 0,823 с.
- **4 теста JavaScript прошли**: порядок API и счётчики, сброс необязательных полей, единственный повторный запрос, причины нехватки карточек. Время прогона — 0,289 с. Эти проверки используют упрощённый DOM.
- Все 8 сценариев отправлены в работающий локальный HTTP API по два раза: ожидаемые исходы и ID совпали, порядок сохранился. Максимальное измеренное время одного ответа — **68,2 мс**. Это локальный замер на текущем компьютере с lexical-ранжированием, не нагрузочный тест.
- В браузере проверены редкая категория, оба вида пустого результата, изменение выдачи между двумя датами и декабрьский выходной. На 6 декабря из 10 ведущих города 9 заняты, показывается 1 карточка с объяснением.
- `python scripts/prepare_embeddings.py --dry-run` подтвердил 66 профилей и 144 текста для подготовки. Сетевых запросов эта команда не выполняет.
- Финальное ревью изменённых файлов не выявило блокирующих ошибок; `git diff --check` проходит.

## Подтверждённые ограничения

- В текущем репозитории используется synthetic fallback-каталог из 66 профилей. Исходный набор организаторов отсутствует.
- Готовый embeddings artifact отсутствует. Реальный сетевой вызов OpenAI не был подтверждён данным репозиторием.
- Публичное развёртывание не настроено; проверка выполняется локально.
- Подбор не бронирует услугу и не подтверждает доступность после выдачи.
- После добавления исходного каталога demo-scenarios.json нужно пересчитать и проверить заново.
